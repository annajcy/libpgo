# Archived Reports

The reports in `static/` and `dynamic/` describe experiments completed before
the unified bunny/dragon, static/dynamic, five-case matrix was introduced. Their
explicit TetGen `a` values and legacy output paths are historical provenance,
not configuration for the current pipeline.

The current pipeline writes machine-readable comparisons and `summary.md` files
under `examples/outputs/tricubic_hermite_fem/<study>/<mode>/`. Replace or extend
these archived reports only after all 20 fresh server runs have completed.
