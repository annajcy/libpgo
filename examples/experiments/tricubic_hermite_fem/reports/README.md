# Experiment Reports

The reports in `static/` describe the fresh bunny and dragon five-case matrices
run on the Linux server on 2026-07-22 at commit `916be0e`. They use the current
manifest-selected tet references, canonical output layout, and five-case
comparison that includes both x8 and x27 cubic-linear refinements.

The reports in `dynamic/` still describe experiments completed before the
unified five-case matrix. Their explicit TetGen parameters and legacy output
paths remain historical provenance until fresh dynamic matrices replace them.

Machine-readable results and generated `summary.md` files live under
`examples/experiments/tricubic_hermite_fem/output/<study>/<mode>/`. The hand-written
reports interpret those artifacts but do not replace them as the source of
numeric truth.
