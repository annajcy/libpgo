\begin{frame}{Question and Reference Policy}
  \begin{block}{Main question}
    Relative to the finest available same-domain tet-linear discretization,
    how do tricubic Hermite and successive cubic-linear refinements compare in
    visible-surface displacement accuracy and global DOF count?
  \end{block}

  \vspace{0.5em}
  \begin{itemize}
    \item Designate independently remeshed \case{tet_L2} as \case{tet_ref} for both models.
    \item Retain the earlier x5-scale tet solve as \case{tet_L0}; add \case{tet_L1} and a tight-tolerance L0 control.
    \item Compare x8 at near-Hermite DOFs, x27 at higher resolution, and the new x64 low-order point.
    \item Treat all L2-relative metrics as numerical comparisons, not certified continuous-solution errors.
  \end{itemize}
\end{frame}

\begin{frame}{Controlled Same-Domain Design}
  \small
  \begin{itemize}
    \item Build an R15 conservative cubic domain from each visible surface.
    \item Generate every tet mesh from that cubic-domain boundary, not directly from the original surface.
    \item Use the original surface for attachment and visible-surface evaluation.
    \item Keep material, gravity, attachment, evaluation surface, code commit, and stopping rules controlled.
    \item L1 and L2 are independent TetGen remeshes, not nested refinements of L0.
  \end{itemize}

\begin{frame}{Primary Metric and Solver Controls}
  \small
  Let $F$ be non-attached original-surface vertices, $A_i$ their lumped areas,
  and $u_{\mathrm{ref}}=u_{\mathrm{tet\_L2}}$.

  \[
    E_{A,\mathrm{rel}} =
    \sqrt{\frac{\sum_{i\in F} A_i\|u_i-u_{\mathrm{ref},i}\|_2^2}
                 {\sum_{i\in F} A_i\|u_{\mathrm{ref},i}\|_2^2}}
  \]

  \begin{columns}[T]
    \begin{column}{0.49\linewidth}
      \textbf{Shared setup}
      \begin{itemize}
        \item Stable Neo-Hookean, $E=10^6$, $\nu=0.45$
        \item Gravity $(0,-9.81,0)$; attachment $10^5$
        \item 300 Newton iterations; standard tolerance $10^{-5}$
      \end{itemize}
    \end{column}
    \begin{column}{0.49\linewidth}
      \textbf{Validity controls}
      \begin{itemize}
        \item L0 repeated at $10^{-6}$ tolerance
        \item Pin residual limit $1.5\times10^{-3}$
        \item RMS reported only as deformation scale, not error
      \end{itemize}
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{What the Evidence Supports}
  \small
  \begin{block}{Supported}
    On both models, Hermite is substantially closer to the designated tet L2
    reference than the near-DOF x8 cubic-linear baseline.
  \end{block}

  \begin{itemize}
    \item Aggressive cubic-linear refinement is monotone toward L2 from base to x8, x27, and x64.
    \item x27 is closer to L2 than Hermite on both models, at about 2.6--2.7x the DOFs.
    \item x64 is the closest cubic method and is competitive with tet L1 at fewer DOFs.
  \end{itemize}

  \begin{alertblock}{Not established}
    Neither tet sequence passes every pre-registered eligibility criterion.
    L2 is the reporting reference, but the experiment does not prove that L2
    is the continuous solution or provide a certified error bound.
  \end{alertblock}
\end{frame}

\begin{frame}{Limitations}
  \small
  \begin{itemize}
    \item Only two geometries and one static load/attachment case per geometry are reported.
    \item L1 and L2 are independent remeshes rather than nested refinements.
    \item L2 has not been repeated at the tighter $10^{-6}$ solver tolerance.
    \item Metrics are original-surface displacement norms; no volume L2 or energy norm is reported.
    \item L2 was designated after observing the convergence runs, so comparisons are descriptive.
    \item Canonical timings use 12 threads; convergence timings use 21 threads.
    \item Each wall time is a single observation without run-to-run dispersion.
  \end{itemize}
\end{frame}

\begin{frame}{Conclusion}
  \small
  \begin{block}{Main result}
    Relative to tet L2, tricubic Hermite improves substantially over the base
    and comparable-DOF x8 cubic-linear discretizations on both dragon and bunny.
  \end{block}

  \vspace{0.6em}
  \begin{itemize}
    \item Dragon: Hermite \pct{2.890} versus x8 \pct{5.162}; x27 reaches \pct{1.977} at 2.63x Hermite DOFs.
    \item Bunny: Hermite \pct{6.744} versus x8 \pct{12.923}; x27 reaches \pct{5.914} at 2.74x Hermite DOFs.
    \item The earlier claim that Hermite is more accurate than x27 is withdrawn for both L2-reference comparisons.
    \item The defensible claim is a Hermite advantage over comparable-DOF x8, not unconditional dominance over refined low-order FEM.
  \end{itemize}
\end{frame}
