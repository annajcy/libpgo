# Archived Benchmark Results

`python_solver_phase_threading/` contains local raw JSON from the retired
Newton phase-executor integration benchmark. The runner and its Newton
threading hooks are no longer part of the active codebase, so these artifacts
are retained only as historical evidence and are not reproducible from the
current public solver API.

The raw JSON remains ignored because benchmark result artifacts are
machine-generated and large. Git history preserves the former runner and
workload definitions.
